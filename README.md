# danielvlad.com

Personal portfolio for Daniel Vlad — DevOps Engineer & Cloud Solutions Architect.

**Tech:** Pure HTML, CSS, and vanilla JavaScript. Zero frameworks. Zero build steps.

**Theme:** Dark mode with green terminal accent. Light/dark toggle.

## Sections
- Hero terminal with DevOps aesthetic
- Trust bar (Microsoft, Roland Berger, Orange)
- Services (CI/CD, Cloud, Security, Free Audit)
- Case studies with real metrics
- Microsoft Azure certifications
- Blog preview
- Testimonials
- Contact form (Web3Forms)
- Footer

## Running locally
```bash
python3 -m http.server 8765
```
Open http://localhost:8765

## Deploy
Static site — deploy to any CDN or static host (GitHub Pages, Netlify, Cloudflare Pages, Azure Static Web Apps).
